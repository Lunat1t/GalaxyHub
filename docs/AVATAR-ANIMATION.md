# Аватар личной комнаты

С версии 1.2.0 в единственной личной комнате снова используется чёрный кот:
`public/sprites/black-cat-v1.png` и соответствующий JSON-атлас. По четыре кадра
для каждого направления, масштаб .18, точка опоры 316/336.

`src/components/personal-room/personal-world.tsx` переключает кадр через каждые
12 фактически пройденных пикселей. В покое и у стены кот возвращается в кадр 0
текущего направления. Дистанция считается после ограничения координат стенами.
Старый риг девушки не подключается, её изображения не загружаются.

Комната рисуется локально без соединения с Colyseus и без других игроков.
Прежние страницы кампуса, Café и проектов перенаправляют на главную.
Ни двери, ни карта, ни чат, ни мебель в сцену не добавляются.
Вход и собственный профиль доступны по `/profile`. Состояние декора и серверное
хранение обстановки пока не добавлены: комната намеренно пустая.

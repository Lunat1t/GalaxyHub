# Анимация аватара

`lavender-doll-v2` содержит 32 кадра ходьбы: восемь фаз для каждого из четырёх
направлений. Три дополнительных кадра содержат только закрытые веки для вида
спереди и сбоку. В покое остаётся тот же нейтральный кадр тела; слой век
накладывается на глаза, не меняя рост и пропорции персонажа.

`src/shared/avatar-motion.ts` вычисляет позу по фактически пройденному расстоянию,
а не по нажатой клавише. У стены ноги останавливаются. На высоких частотах
отрисовки 40 мс без смещения считаются промежутком между тиками симуляции;
после настоящей остановки шаг завершается за следующие 160 мс.
Перемещение, коллизии, сетевые сообщения и серверная симуляция не меняются.

`src/components/campus/avatar-animation.ts` применяет позу к спрайту внутри
контейнера: небольшие перенос веса, наклон, дыхание и редкое моргание.
Контейнер, метка игрока и подпись остаются привязаны к игровой позиции.
Колебания волос и подола заложены в кадрах; отдельного физического скелета нет.
Настройка `prefers-reduced-motion` отключает декоративные колебания и моргание,
сохраняя необходимые для чтения движения кадры шага.

Контроллер общий для кампуса, локального игрока Café и остальных участников.
Он не использует интервалы или таймеры; слои спрайта уничтожаются вместе с
контейнером при выходе из комнаты. После переподключения или телепорта фаза
переустанавливается без гигантского шага.

Проверка: `npm run check:avatar`. Она включает дискретную симуляцию 60 Гц
при рендеринге 20/30/60/144/240 Гц, остановку, блокировку, направления,
телепорт, дыхание, независимое моргание и режим уменьшенного движения.

# Запуск Café на своём компьютере

Нужен Node.js 22.19 или новее (рекомендуется Node.js 24 LTS).

Распакуйте архив и откройте терминал в папке GalaxyHub.

```sh
npm ci
cp .env.example .env
npm run dev
```

В PowerShell вместо `cp` можно использовать `Copy-Item .env.example .env`.
Если `.env` уже существует, сохраните его и не заменяйте примером.

Когда в терминале появится сообщение Ready, откройте:
http://localhost:3000/cafe

Введите имя гостя и нажмите «Войти в Café».
Для проверки нескольких участников откройте вторую вкладку под другим именем.
Не закрывайте терминал во время работы. Ctrl+C остановит оба сервера.

Для гостевого Café не требуются Docker, PostgreSQL или доступ к Supabase.
Для авторизации через Supabase отдельно заполните публичные настройки в `.env`:
см. README.md. Настройки и ключи из облачного окружения в архив не включены.
